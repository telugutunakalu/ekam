# EKAM - Cinema . Saahityam

A cultural event website bringing literature and cinema together on a single platform.

## Event Details

- **Date:** February 14, 2026
- **Venue:** T-Works, Hyderabad
- **Time:** 9:00 AM - 9:00 PM

## Organized By

- **Telugu Collective** - A Section 8 Company focused on promoting Telugu literature
- **The Psychic Filmmaker** - A knowledge-driven community for filmmakers

## Website Features

- Mobile-first responsive design
- Smooth scroll animations
- Interactive gallery with lightbox
- Statistics counter animation
- Fixed header with scroll effect
- Full-screen mobile navigation

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (No frameworks)
- Google Fonts (Poppins, Playfair Display)

## Deployment

This website is designed to be deployed on GitHub Pages:

1. Push to GitHub repository
2. Go to Settings → Pages
3. Select `main` branch as source
4. Your site will be live at `https://username.github.io/ekam_website/`
